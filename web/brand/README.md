# Platform wordmarks

The landing shows "for <wordmark>" under the title when a content type other than Platform is
selected. Drop the official file here and it is used as is, at the height set in TYPE_BRAND
(app.js). No code change is needed.

- `social.svg` - the current Instagram wordmark, from Meta's brand resource centre
- `youtube.svg` - the YouTube logo, from Google's brand resource centre

Until a file is present the type's name is drawn as text instead.

Both marks are trademarks of their owners. Check each company's brand guidelines before this
goes public: they set minimum size, clear space, colour and, importantly, whether a phrase like
"for Instagram" is allowed or reads as an endorsement.
